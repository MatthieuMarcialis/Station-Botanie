# Station-Botanie
Projet de Communication Sans Fil pour le groupe Marcialis-Yerofeiev

Ce projet consistait en la réalisation d'une station qui mesure la température ambiente ainsi que l'humidité de la terre autour d'une plante pour l'envoyer à un utilisateur.
Le projet a été complètement réalisée. La carte capte la température et l'humidité avant de l'envoyer à un serveur TTN, qui ensuite l'envoit à un Dashboard de Tago.io par un Webhook pour le rendre lisible pour l'utilisateur.

Ce dépôt contient toutes les informations sur ce projet, incluant:
  - Le code
  - Les .md des participants expliquant leur participation
  - Le Gantt du projet
  - La présentation intérmediaire et finale.
